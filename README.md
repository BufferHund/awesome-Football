# ⚽ Awesome Football - Match Simulator

A simple and interactive football match simulator built with HTML, CSS, and JavaScript.

## Features

- **Live Match Simulation**: Watch a simulated football match unfold in real-time
- **Team Selection**: Choose from popular football teams like Manchester United, Liverpool, Barcelona, Real Madrid, Bayern Munich, and Juventus
- **Dynamic Scoring**: Goals are scored randomly throughout the match
- **Match Events**: View real-time match events including goals, yellow cards, substitutions, and more
- **Match Controls**: Start, pause, and reset matches at any time
- **Responsive Design**: Works beautifully on desktop and mobile devices

## How to Use

1. **Open the App**: Simply open `index.html` in your web browser
2. **Select Teams**: Choose your home and away teams from the dropdown menus and click "Set Teams"
3. **Start Match**: Click the "Start Match" button to begin the simulation
4. **Watch**: Observe as the match progresses with random goals and events
5. **Controls**: Use Pause to pause the match or Reset to start over

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `app.js` - Match simulation logic and interactivity

## Technical Details

- Pure vanilla JavaScript (no frameworks required)
- CSS3 with gradients and animations
- Fully responsive design
- Object-oriented programming approach

## Installation

No installation required! Just clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/BufferHund/awesome-Football.git
cd awesome-Football
# Open index.html in your browser
```
